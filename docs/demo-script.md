# SpecBuddy Demo Video Script

Target length: 3 to 5 minutes.

## Open

> "Coding agents can move fast, but they inherit the quality of the requirements
> we give them. Bad specs do not always fail loudly. They become bugs, rework, and
> inconsistent agent behavior later."

## Product

> "SpecBuddy is a requirements quality gate for AI-assisted software delivery. It
> helps teams turn rough Markdown requirements into coding-agent-ready
> specifications before implementation begins."

## Demo

1. Paste a weak Markdown requirements document.
2. Click **Analyze**.
3. Show the score, verdict, tier, and severity counts.
4. Open findings and point to line numbers, check IDs, and suggested rewrites.
5. Apply one supported fix.
6. Show the score improve and the finding count drop.
7. Show the accepted rewrite.
8. Open the Mission Board and explain that progress is derived from the current
   result, not persisted backend state.
9. Open the full Markdown report for handoff.

## Build Reflection

> "For this first version, I kept the scope intentionally narrow: Markdown in,
> deterministic checks, rewrite overlays, rescoring, and report export. Direct
> imports from DingTalk, Zoom, Teams, whiteboards, OCR, or speech-to-text are
> future work, not current features."

## Close

> "Same coding agent. Clearer specs in. Better software out. SpecBuddy catches
> ambiguity before a coding agent turns it into implementation drift."
