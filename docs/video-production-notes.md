# SpecBuddy Video Production Notes

Use these notes for the hackathon demo video.

## Target

- Length: 3 to 5 minutes
- Format: screen recording with optional voiceover
- Content: working app, real analysis result, rewrite loop, Mission Board, report
- Links: upload to YouTube, Google Drive, or Loom with public access enabled

## Required Shots

1. App open with `SpecBuddy` visible in the header.
2. Rough Markdown requirements pasted into the import panel.
3. Analyze action.
4. Score, verdict, tier, and severity counts.
5. Findings with line numbers and suggested deterministic rewrites.
6. Apply fix action.
7. Updated score/findings.
8. Accepted rewrites.
9. Mission Board.
10. Full Markdown report.

## Voiceover Anchor

SpecBuddy helps teams turn weak requirements into coding-agent-ready
specifications before coding agents start building.

## Claims To Avoid

- Do not claim live DingTalk, Zoom, Teams, OCR, speech-to-text, whiteboard, or
  file-import integrations are implemented.
- Do not claim CodeBuddy built the project unless confirmed separately.
- Do not present deterministic rewrites as AI-generated rewrites.
